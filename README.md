# 🎥 AlgoReplay

**AlgoReplay** — інструмент для розробників, який записує сесії кодування й перетворює їх на відео з інтерактивним таймлайном подій: збереження файлів, запуски, копіювання, простої та власні мітки. Створений для студентів, учасників олімпіад з програмування (ICPC тощо) та всіх, хто хоче переглядати й аналізувати свій робочий процес.

## 🌐 [Сайт](https://landing-algo-replay.vercel.app/)

## 🎯 Навіщо це потрібно

- **Розбір власної сесії** — переглянути запис із синхронізованими подіями замість сирого відео без контексту.
- **Чесність на змаганнях** — режим "Олімпіада" фіксує спроби відкрити месенджери чи AI-чати під час розв'язання задачі.
- **Навчальний контент** — швидкий експорт у розділи YouTube, Markdown-звіт або JSON для подальшої обробки.
- **Нотатки під час роботи** — миттєва дошка для замальовок чи пояснень, без виходу із застосунку.

---

## 🛠 Як це працює

| Компонент | Що робить |
|---|---|
| Захоплення екрана | `Windows.Graphics.Capture` + апаратне кодування (NVENC / AMF / QSV) через FFmpeg, з fallback на `libx264` |
| Захоплення звуку | Мікрофон через NAudio |
| Моніторинг подій | Збереження файлів, Undo, запуск/дебаг, перемикання вкладок IDE, простої, відкриття/закриття IDE |
| Контроль чесності | `BlacklistMonitor` — виявляє месенджери та AI-чат-сервіси поверх активного вікна |
| Зберігання | SQLite + Dapper, з версійними міграціями схеми |
| Плеєр | LibVLCSharp з мітками подій прямо на таймлайні |
| Дошка | Окреме вікно для малювання/нотаток поверх застосунків |

Стек: **.NET 8 + WPF**, MVVM (CommunityToolkit.Mvvm).

## 🚀 Режими запису

| Режим | Деталізація | Можна редагувати події |
|---|---|---|
| 🏆 Олімпіада | Лише базові дії: буфер, збереження, run/debug, простої, маркери | Ні — фіксований |
| 📚 Навчання | Базові + Undo | Так |
| 💼 Робота | Базові, без простоїв | Так |
| 🙂 Особистий | Максимум: + автозбереження, перемикання файлів, IDE-події | Так |

Режим, якість відео та список подій для логування налаштовуються у вікні **Налаштування** й зберігаються між запусками.

### Глобальні (працюють у будь-якому застосунку)

| Клавіші | Дія |
|---|---|
| `Ctrl Shift R` | Старт / Стоп запису |
| `Ctrl Shift M` | Додати маркер (тільки під час запису) |
| `Ctrl Shift S` | Скріншот з анотацією (тільки під час запису) |
| `Ctrl Shift W` | Відкрити дошку |

### Редактор скріншотів / Дошка

| Клавіша | Дія |
|---|---|
| `S` | Виділення (лише редактор скріншотів) |
| `A` | Стрілка |
| `R` | Прямокутник |
| `P` | Олівець |
| `T` | Текст |
| `M` | Маркер-виділення (лише редактор скріншотів) |
| `E` | Гумка |
| `Ctrl Z` | Скасувати |
| `Ctrl S` | Зберегти (лише редактор скріншотів) |
| `Ctrl Delete` | Очистити все (лише дошка) |
| `F11` | На весь екран (лише дошка) |
| `Ctrl Scroll` | Товщина пензля |
| `Delete` | Видалити обраний елемент |

## 📤 Експорт сесій

Зі вкладки **Сесії** будь-яку сесію можна експортувати:

- **JSON** — повні дані сесії й подій для подальшої обробки;
- **Markdown** — звіт-таблиця з усіма подіями;
- **YouTube chapters** — готовий список розділів за таймкодами.

---

## 🖥 Системні вимоги

- Windows 10 (1903+) / Windows 11
- .NET 8.0 Runtime
- Відеокарта з апаратним H.264 (NVIDIA / AMD / Intel) — бажано, інакше програмний кодек
- FFmpeg визначається автоматично

## 📥 Встановлення

1. Відкрити [Releases](https://github.com/DakotaOlha/Diploma/releases)
2. Завантажити `AlgoReplay_v1.0.0.zip`
3. Розпакувати в будь-яку папку
4. Запустити `Diploma.exe`

> Windows SmartScreen може попередити про "невідомого видавця" — натиснути **"Докладніше" → "Виконати в будь-якому разі"**.

## 📸 Інтерфейс

- **Оверлей** — плаваюча панель: запис, мікрофон, маркер, скріншот, дошка, сесії, налаштування, статус диска
- **Сесії** — список записів, пошук по подіях, перейменування, видалення, експорт
- **Плеєр** — відео + список подій + кольорові мітки на таймлайні
- **Редактор скріншотів** — стрілки, фігури, олівець, текст, маркер, гумка
- **Дошка** — вільне малювання й нотатки поверх будь-яких застосунків
- **Налаштування** — якість відео, режим за замовчуванням, події логування, довідка з хоткеїв
