# 🎥 AlgoReplay

**AlgoReplay** — це спеціалізований інструмент для розробників, призначений для запису сесій кодування, аналізу робочого процесу та створення інтерактивних таймлайнів подій. Проект орієнтований на студентів, учасників олімпіад з програмування та професіоналів, які прагнуть покращити свою продуктивність.

---

## 🛠 Архітектура та Технології

Проект побудований на базі **.NET 8** та **WPF** з використанням архітектурного патерну **MVVM** (CommunityToolkit.Mvvm).

### Ключові компоненти:

- **Захоплення екрану:** Використовує сучасний `Windows.Graphics.Capture` API для високопродуктивного запису з апаратним кодуванням (NVENC, AMF, QSV) через **FFmpeg**.
- **Захоплення звуку:** Реалізовано за допомогою бібліотеки **NAudio**.
- **Моніторинг активності:**
    - `FileSystemMonitor`: відстежує збереження файлів з вихідним кодом.
    - `ProcessMonitor` та `WindowTitleMonitor`: реєструють відкриття IDE та перемикання між файлами за допомогою Win32 API.
    - `InputMonitorService`: аналізує гарячі клавіші та періоди бездіяльності (Idle).
- **База даних:** Зберігання сесій та логів подій у **SQLite** за допомогою **Dapper**.
- **Плеєр:** Інтегрований **LibVLCSharp** для перегляду записів з накладанням інтерактивних маркерів подій на таймлайн.

## 🚀 Режими запису

Додаток підтримує чотири режими, що визначають рівень деталізації логування подій:

1. **🏆 Олімпіада (Olympic):** Суворий режим для змагань (ICPC тощо). Записує лише базові дії: роботу з буфером обміну, збереження файлів, запуск/відладку та ручні маркери.
2. **📚 Навчання (Learning):** Для туторіалів. Додатково відстежує операції скасування дій (Undo).
3. **💼 Робота (Work):** Оптимізований для робочих сесій та код-рев'ю.
4. **🙂 Особистий (Personal):** Максимальна деталізація. Записує все, включаючи автоматичні збереження файлів, перемикання між вкладками IDE та моніторинг фонових процесів.

## ⌨️ Гарячі клавіші

Для управління записом без перемикання на вікно програми використовуються глобальні хоткеї:

| **Комбінація** | **Дія** |
| --- | --- |
| `Ctrl + Shift + R` | Почати або зупинити запис |
| `Ctrl + Shift + M` | Додати ручний маркер (з коментарем) |
| `Ctrl + Shift + S` | Зробити скріншот з можливістю анотації |

## 🖥 Системні вимоги

- **ОС:** Windows 10 (версія 1903 або новіша) / Windows 11.
- **Платформа:** .NET 8.0 Runtime.
- **Графіка:** Відеокарта з підтримкою апаратного кодування H.264 (NVIDIA, AMD або Intel) для стабільного FPS.
- **Додатково:** Встановлений FFmpeg (автоматично визначається системою).

## 📥 Інструкція із запуску

1. Перейдіть у розділ [Releases](https://github.com/DakotaOlha/Diploma).
2. Завантажте архів `AlgoReplay_v1.0.0.zip`.
3. Розпакуйте архів у зручне місце.
4. Запустіть файл `Diploma.exe`.

*Примітка: При першому запуску Windows може попередити про "невідомого видавця" (SmartScreen). Натисніть "Докладніше" -> "Виконати в будь-якому разі".*

## 📸 Інтерфейс користувача (UI)

*Тут будуть скріншоти після фінального тестування:*

- **Головна вкладка:** Керування записом, вибір мікрофона та режиму.
- **Оверлей:** Компактне вікно поверх усіх програм для моніторингу статусу запису та вільного місця на диску в реальному часі.
- **Плеєр:** Відео з синхронізованим списком подій та інтерактивними мітками на таймлайні.
- **Редактор скріншотів:** Інструменти для малювання стрілок, прямокутників та додавання тексту поверх кадру.
